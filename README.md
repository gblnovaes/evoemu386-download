# EvoEmu386 — downloads

IDE + emulador **x86 (80386 ao Pentium)** com depurador integrado.

**Baixe na página [Releases](../../releases/latest):**
- **Windows:** `EvoEmu386-Setup-<versão>.exe` (instalador) ou `EvoEmu386-<versão>-portable.exe` (roda sem instalar).
- **Linux:** `EvoEmu386-<versão>-linux-x86_64.AppImage` — dê permissão com `chmod +x` e execute. Se não abrir, instale `libfuse2`.

No Windows, na primeira execução pode aparecer "O Windows protegeu seu computador" (o app ainda não é assinado digitalmente): clique em **Mais informações → Executar assim mesmo**.

Este repositório contém apenas os executáveis.
